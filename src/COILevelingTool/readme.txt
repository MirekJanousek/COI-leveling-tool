COI Terrain Leveling Tool 0.1.0
================================

Supported game: Captain of Industry v0.8.6a only.

Installation
------------
Extract the COILevelingTool directory into:
%APPDATA%\Captain of Industry\Mods

The resulting directory must contain manifest.json and COILevelingTool.dll.
Enable the mod when creating a game. Adding it to an existing save is not yet
verified and is disabled in this release manifest.

Diagnostics
-----------
Inspect %APPDATA%\Captain of Industry\Logs if the mod is unavailable. The mod
fails closed when the installed game APIs or version do not match v0.8.6a.

Removal
-------
Removal from saved games has not yet been verified. Complete or cancel every
pending leveling structure and make a backup before disabling or deleting the
mod. The manifest conservatively disallows removal until the verification
matrix has passed.
